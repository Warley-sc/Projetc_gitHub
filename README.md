# Projetc_gitHub
 Armazenamento de projetos do GitHub como função de estudos e criação de eventos 

 Arquivo 1 : leitura de arquivos no prompt.
 
 Arquivo 2 : leitura de arquivos no prompt e troca de valores.

 Arquivo 3: criação de um programa que recebe 2 valores no terminal, Nome e Nota e detremina se o aluno etá aprovado ou não.

Arquivo 4: Criação de um programa que recebe 2 valores, sendo eles: Nota e Nome. Assim, que recebe esses valores é feito uma filtragem desses valores, na onde se faz uma ordenação em relação as notas e em uma estrutura condicional é revelado se o aluno esta aprovado ou reprovado.

Arquivo 5: Criação de um arquivo que gera aleatoriamente 6 numeros, esses numeros são baseados na loteria, então é de 1 ate 60.

Arquivo 6: desenvolvimento de arrays colocado um array no metado push de objetos
